# WalkerEngine

Бот маршрутов для Drakensang Online (Studio: `WalkerRouteBuilder`).

## Перед запуском

1. Собрать: `dotnet build WalkerEngine.sln` (.NET 9, Windows).
2. Запустить игру в **1024×722** (под это калиброваны клики UI и миникарта).
3. Рядом с exe должен лежать `follow-config.json` (копируется из `WalkerRouteBuilder/follow-config.json` при сборке).
4. В конфиге указать заголовок окна и область миникарты (см. ниже).
5. Сценарии и цепочки — в `Database/` (каталог `library.json`).

Меню **Прогон → Конфиг ведения…** открывает `follow-config.json` в редакторе.

## Горячие клавиши (глобальные)

| Клавиша | Действие |
|---|---|
| **F6** | Запуск сценария / цепочки |
| **F8** | Запуск выбранного блока (или нескольких) |
| **F7** | Стоп |
| **F9** | Снять точку для блока «Нажатия» |

В тулбаре:
- **«Автоперезапуск»** — вкл/выкл `restart.enabled` (пишется в `follow-config.json`). Нужен ещё `executablePath`.
- **«Запуск игры»** — вручную тот же цикл (kill → лаунчер → логин → персонаж → мир). Стоп — **F7**.

## `follow-config.json` — что править

### Обязательно под своё окно

| Параметр | Зачем |
|---|---|
| `gameWindowTitleContains` | Часть заголовка окна (например `Drakensang Online`). Без этого окно не находится. |
| `window.clientWidth` / `clientHeight` | Размер клиентской области. Эталон: **1024×722**. |
| `mapInClient` | Миникарта внутри клиента: эталон **x=30, y=69, width=360, height=320**. Если карта «плывёт» — подгоните эти четыре числа. |

`mapRegion` (абсолютные координаты экрана) нужен только если `mapInClient` не задан.

### Старт и фокус

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `startDelayMilliseconds` | `3000` | Пауза после старта, пока поднимется окно игры. |
| `focusSettleMilliseconds` | `80` | Пауза после клика фокуса. |
| `captureIntervalMilliseconds` | `250` | Как часто снимать миникарту (мс). |

### Ведение по маршруту

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `lookAheadPixels` | `80` | Точка прицеливания впереди по пути. |
| `rejoinLookAheadPixels` | `28` | Прицел при возврате на маршрут. |
| `arrivalDistancePixels` | `4`…`10` | Когда считать точку достигнутой. |
| `clickDistancePixels` | `180` | Дальность клика по земле. |
| `headingToleranceDegrees` | `55` | Допуск направления. |
| `wallClearancePixels` | `6` | Отступ пути от стен. |

### Застревание

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `stuckMovePixels` | `2` | Минимальный сдвиг, чтобы не считать «стою». |
| `stuckSampleCount` | `3` | Сколько кадров подряд без сдвига. |
| `stuckRecoveryMilliseconds` | `2000` | Через сколько мс без движения включать вывод. `0` — выкл. |
| `stuckRecoveryShiftPixels` | `8` | Сдвиг на карте, после которого путь перестраивается. |
| `stuckRecoveryKeys` | `[]` | Клавиши по кругу, если оборот не помог (имена как у Keys: `D1`, `Space`…). |

Диалог **Прогон → Застревание…** правит часть этих полей без ручного JSON.

### Клавиши скиллов

```json
"pressKeys": true,
"keys": [
  { "key": "D1", "intervalMilliseconds": 300 },
  { "key": "D3", "intervalMilliseconds": 1000 },
  { "key": "D4", "intervalMilliseconds": 6000 }
]
```

`key` — имя из WinForms `Keys` (`D1`…`D0`, `F1`…, буквы). Нельзя вешать на **F6 / F7 / F9**.

### Перезапуск игры (`restart`)

Если миникарта (или зелёный маркер игрока) не видна дольше `minimapLossMilliseconds`, клиент закрывается и поднимается заново. Пока идёт блок **«Войти в дверь»** или полоса загрузки — таймер не крутится.

| Параметр | Смысл |
|---|---|
| `enabled` | Вкл/выкл. Реально работает только вместе с непустым `executablePath`. |
| `minimapLossMilliseconds` | Сколько ждать пропавшую миникарту (по умолчанию 20000). |
| `maxAttempts` | Сколько полных циклов «убить → запустить → войти». |
| `executablePath` | Путь к клиенту (`thinclient.exe`). |
| `executableArguments` | Аргументы (для 64-bit DSO: `-x86_64`). |
| `processName` | Имя процесса для Kill (без `.exe`), напр. `thinclient`. |
| `username` / `password` | Логин (в git — только тестовые `test_user` / `test_password`). |
| `server` + `servers[]` | Имя сервера и клики строк (`x`/`y` — доли окна 0…1). |
| `characterX` / `characterY` | Клик по слоту персонажа (только координаты 0…1, без ника). |
| `launcherWindow` | Куда поставить окно лаунчера перед кликами. |
| `usernameX/Y`, `passwordX/Y`, `startGameX/Y` | Клики по полям и «Начать игру». |
| `stepTimeoutMilliseconds` | Таймаут одного этапа (логин, загрузка, мир). |
| `clickDelayMilliseconds` | Пауза после клика/ввода при запуске (мин. 300). |

Боевые логин/пароль/путь — в `follow-config.secrets.json` рядом с exe (файл в `.gitignore`). Шаблон: `follow-config.secrets.json.example`.

После успешного входа окно ставится по обычному `window` (1024×722), сценарий текущего круга начинается сначала.

### Прочее

| Параметр | Смысл |
|---|---|
| `antagonistPauseMilliseconds` | Пауза после финиша маршрута перед бегом к антагонисту. |
| `character.offsetFromCenterX/Y` | Смещение «персонажа» от центра окна (для кликов). |
| `invertX` / `invertY` / `rotationDegrees` | Если миникарта зеркальная или повёрнута. |

Логи: папка `logs/` в корне репозитория. Режим снимков — переключатель **«Лог: …»** в тулбаре.
