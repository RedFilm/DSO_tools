# Чеклист недостающих данных для DrakenHub

Ниже — то, чего нет в `Описание.txt` и референсах, поэтому реализовано с разумными допущениями или оставлено на доработку.

## Критично для точности макросов

- [ ] **Как именно продаётся предмет в магазине**  
  Сейчас: ЛКМ по центру ячейки. Нужно уточнить: обычный клик / Ctrl+клик / Shift+клик / отдельная кнопка подтверждения / двойной клик.

- [ ] **Как кладётся предмет в плавильню**  
  Сейчас: ЛКМ по подходящим ячейкам после открытия плавильни ПКМ. Нужен точный порядок: ПКМ/ЛКМ, подтверждение, ожидание анимации.

- [ ] **Размер сетки инвентаря в игре**  
  Сейчас по умолчанию `10×6`. Нужны реальные `Columns` / `Rows` для целевого клиента.

- [ ] **Пресеты координат под разрешения**  
  В UI есть `1366×768`, `1920×1080`, `2560×1440`, `3840×2160`, но готовых пакетов координат/сетки/точек редкостей нет. Нужны эталонные JSON или таблицы значений.

- [ ] **Допуск сравнения цвета и правило матча**  
  Сейчас: Euclidean distance, допуск `18`, нужно совпадение ≥50% точек. Нужны эталонные RGB/допуск и правило (все точки / majority / any).

- [ ] **Задержки между действиями продажи/открытия магазина**  
  Сейчас эвристики (`SellClickDelayMs` и множители). Нужны проверенные тайминги для стабильной работы на разных ПК/пинге.

## Поведение UI / UX из описания

- [ ] **Точные дефолтные значения сетки**  
  `CellSize`, `GapX/Y`, `TabOffsetX`, `TabMarkerSize`, `CrosshairSize` — сейчас стартовые числа, не из эталона.

- [ ] **Синхронизация «Основная панель»**  
  Реализована записью одного значения в Fast Mount / Extra Skill / Gear Swap. Нужно подтвердить, должна ли правка в одном месте мгновенно обновлять подписи кнопок на других вкладках без пересборки страницы.

- [ ] **Использование «Кнопка назад» в телепорте**  
  Координата сохраняется, но в макросе не используется: нет сценария, когда нужен Back (несколько уровней карты и т.п.).

- [ ] **Точный sequence Jump Mount / Gear Swap**  
  Реализовано по текстовому описанию. Нужна покадровая/покадровая проверка на живой игре (открыт ли инвентарь в момент клика по плащу, ПКМ vs ЛКМ для экипа).

## Технические пробелы

- [ ] **Привязка к окну игры**  
  Сейчас абсолютные экранные координаты. Нет поиска окна клиента, относительных координат, поддержки fullscreen/borderless/windowed и сдвига окна.

- [ ] **Мультимонитор / DPI scaling**  
  Overlay берёт `VirtualScreen`, DPI PerMonitorV2 включён, но нет отдельной калибровки под 125%/150% scaling.

- [ ] **Иконка приложения и фирменные ассеты**  
  В папке только референс-скриншоты, нет `.ico` / логотипа.

- [ ] **Точный визуальный стиль**  
  Цвета и раскладка приближены к скринам (тёмный фон, orange/cyan/green/red). Нет пиксель-перфект шрифтов, скруглений и кастомных ComboBox из оригинала.

- [ ] **Автокликер vs RegisterHotKey**  
  Hold/Toggle слушается low-level keyboard hook (чтобы работать «пока нажата»). Нужно подтвердить, не конфликтует ли это с античитом/оверлеем игры.

- [ ] **Безопасность / ToS игры**  
  Вне скоупа кода, но для релиза нужно явное решение: это личный оффлайн-инструмент или публичный продукт.
